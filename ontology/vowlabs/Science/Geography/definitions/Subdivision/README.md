# Subdivision

Canonical code: `S:G:SD`. [Definition](index.json).

A subdivision is an administrative or constituent part of a country, such as a
state or province. It can qualify the location of a person, address or activity.
Its relationship to a country is distinct from an address format or address-use
role. A subdivision reference does not prove residence or jurisdiction.

Named entries live in reference datasets. The [states dataset](../../data/states/README.md)
currently provides the 50 US states; California is `US-CA`. Districts and territories
are not classified as states. No finer subclasses are defined here.
